# 🎓 EduCore: School Management System

## 📌 Introduction
EduCore is a web-based School Management System designed to automate and streamline university processes such as enrollment, billing, grading, and academic record management. It reduces manual work and improves efficiency for students, faculty, and administrators.

---

## 🎯 Objectives
- Automate enrollment, billing, and grading processes  
- Centralize student and academic records in one system  
- Improve efficiency and reduce manual paperwork  
- Provide secure role-based access for users  

---

## 📚 System Features / Modules
- 🔐 User Login System (Admin & Student)  
- 🧑‍💼 Admin Dashboard  
- 🎓 Student Dashboard  
- 📝 Enrollment Management  
- 📊 Grade Management System  
- 💰 Billing & Payment Records  
- 📄 Report Generation  

---

## 🏗️ System Architecture
- **Frontend:** HTML, CSS  
- **Backend:** PHP  
- **Database:** MySQL  

---

## 🛠️ Technologies Used
- PHP  
- MySQL  
- HTML  
- CSS  
- XAMPP (Local Server)  

---

## 👥 User Roles
- **Administrator:** Manages users, enrollment, grades, and reports  
- **Student:** Views enrollment status, grades, billing, and profile  

---

## 🗄️ Database Overview
Main database tables include:
- Students  
- Users  
- Enrollment  
- Courses  
- Grades  
- Billing  

---

## 🔄 System Workflow
1. User logs in (Admin or Student)  
2. Admin manages enrollment, courses, and records  
3. Students view their dashboard and academic information  
4. System stores and retrieves data using MySQL
